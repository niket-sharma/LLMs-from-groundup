# Module 2 — Inference Optimization

M2 builds the mechanisms that make autoregressive models practical at serving
time. Each subsection is added in dependency order: cached decoding first,
attention variants next, then memory scheduling and higher-level algorithms.

Current implementation: **2.1 KV cache**. Read the canonical guide at
[`docs/modules/m2_inference_opt/index.md`](../../docs/modules/m2_inference_opt/index.md).
